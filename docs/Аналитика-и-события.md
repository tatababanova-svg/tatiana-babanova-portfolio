# Аналитика и измеряемые действия

Сайт размечен для измерения действий, важных для карьерной воронки.

| Событие | Что означает |
| --- | --- |
| `hero_cases` | переход из hero к кейсам |
| `case_it-flow` | открытие кейса о 460 IT-задачах |
| `case_it-service` | открытие кейса об IT-сопровождении |
| `case_migration` | открытие кейса о миграции |
| `case_automation-1c` | открытие кейса об автоматизации 1С |
| `case_dashboard` | открытие кейса об управленческом дашборде |
| `case_fixed-deadline` | открытие кейса о трёх проектах за 90 дней |
| `resume_pdf` | открытие PDF-резюме |
| `contact_telegram` | переход в Telegram |
| `contact_email` | переход к email |
| `contact_phone` | нажатие на номер телефона |

Без подключённого аналитического провайдера разметка ничего не отправляет и не ставит cookies. При подключении Plausible или Umami события передаются автоматически через общий обработчик.

При публикации на Netlify базовые посещения, страницы и источники можно собирать через Netlify Web Analytics без клиентского скрипта. Целевые клики требуют подключения провайдера событий либо отдельного first-party endpoint.
