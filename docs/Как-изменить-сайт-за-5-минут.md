# Как изменить сайт самой за 5 минут

## Текст, цифра или порядок блока

1. Откройте папку `content` в репозитории.
2. Выберите нужный файл по таблице в `README.md`.
3. Измените только значение после двоеточия, сохранив кавычки, запятые и квадратные скобки.
4. Сохраните изменение в отдельной рабочей ветке.
5. Откройте preview и проверьте desktop и mobile.
6. Публикуйте production только после того, как preview согласован.

Пример изменения цифры:

```json
{"value":"31","label":"проект запущен или завершён"}
```

## Скрыть или вернуть кейс

Самый безопасный способ — попросить Codex убрать или вернуть объект кейса в `content/cases.json` или `content/other-projects.json`. Так не нарушатся запятые и ссылки навигации.

## Заменить фотографию

1. Подготовьте вертикальный JPG без текста.
2. Назовите файл `tatiana-babanova.jpg`.
3. Замените одноимённый файл в `public`.
4. Проверьте кадрирование на 1440 px и 390 px.

## Заменить PDF

1. Экспортируйте утверждённое полное резюме в PDF.
2. Назовите файл `tatiana-babanova-project-manager.pdf`.
3. Замените одноимённый файл в `public`.
4. В preview нажмите обе кнопки «PDF-резюме» и проверьте открытие файла.

## Важно

- Не меняйте значения `id`, `target` и `caseTargets` без синхронной проверки ссылок.
- Не добавляйте цифры, альтернативы и полномочия, которых нет в подтверждённых материалах.
- Коммерческие результаты формулируйте как «по данным бизнеса, с проектом были связаны…».
