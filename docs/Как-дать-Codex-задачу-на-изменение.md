# Как дать Codex задачу на изменение

Скопируйте шаблон и заполните только нужные строки.

```text
КОНТЕКСТ: [блок или кейс]
ИЗМЕНИТЬ: [точная правка]
СОХРАНИТЬ: [что нельзя менять]
МАСШТАБ: [один компонент или весь сайт]
ПРОВЕРИТЬ: [desktop 1440 / mobile 390 / оба]
ПУБЛИКАЦИЯ: только preview; production не трогать до моего подтверждения
```

Для трёх вариантов:

```text
Сделай 3 варианта только [hero / diagram / card / wording].
Не меняй остальную страницу, факты и структуру.
Для каждого кратко объясни отличие.
Сначала покажи desktop + mobile и остановись до моего выбора.
```

Для смешивания согласованных решений:

```text
Берём Variant B как основу.
Из A перенеси [элемент], из C — [элемент].
Всё остальное в Variant B не менять.
Сначала покажи preview desktop + mobile.
```

Для обновления фактов приложите новое полное и короткое резюме и укажите, какое из них новее. Короткое резюме используется как контроль уже известного работодателю, полное — как источник подробностей для сайта.
