# Татьяна Бабанова — карьерный сайт Project Manager

Одностраничный карьерный сайт второго уровня после краткого резюме на hh.ru. Он раскрывает не перечень обязанностей, а управленческие решения: диагностику, критерии выбора, зависимости, стоимость ошибки, границы полномочий, внедрение и пользовательскую приёмку.

## Согласованная версия

- визуальная система: **Cobalt Index**;
- motion-сценарий: **Control Path**;
- главная страница: `/`;
- контент: отдельные JSON-файлы в `/content`;
- production не публикуется без отдельного подтверждения владельца.

## Публикация

- репозиторий: GitHub;
- preview и production: Netlify;
- ветка предварительного просмотра: `netlify-preview`;
- production-ветка: `main`;
- редактор контента: Netlify Visual Editor + Git CMS после первого успешного preview;
- предпочтительный домен после отдельного согласования: `babanova.pro`.

## Где что менять

| Файл | Содержание |
| --- | --- |
| `content/profile.json` | hero, навигация, метод работы, сводные показатели |
| `content/metrics.json` | навигационные метрики |
| `content/cases.json` | шесть подробных кейсов и схемы «до → решение → после» |
| `content/other-projects.json` | восемь раскрывающихся мини-кейсов |
| `content/experience.json` | карьерная история |
| `content/tools.json` | инструменты и подходы |
| `content/education.json` | образование и языки |
| `content/contacts.json` | контакты и ссылка на PDF |
| `content/seo.json` | SEO title и description |

Фотография хранится в `public/tatiana-babanova.jpg`, PDF — в `public/tatiana-babanova-project-manager.pdf`.

## Проверка перед публикацией

```bash
npm ci
npm run lint
npm run build
```
